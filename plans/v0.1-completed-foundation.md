## 1. Executive Summary

Deliver a **minimal viable open-source foundation** for deterministic LLM integration testing. v0.1 provides a pytest plugin with an `@llm_vcr` decorator, an httpx `VCRTransport` that records/replays HTTP exchanges as YAML cassettes, and automatic secret redaction — enabling CI runs with zero API keys. Sync httpx only; streaming and semantic matching deferred to v0.2.

---

## 2. Problem Statement

- Code that calls LLM APIs is slow, flaky, and expensive to test in CI
- Hand-written mocks drift from real API request/response shapes
- Generic HTTP VCR libraries (e.g., VCR.py) lack LLM-aware redaction and request normalization
- Teams need committable, human-readable fixtures that replay offline with pytest

## 4. Non-Goals (v0.1)

- SSE streaming chunk replay
- Tool-call multi-step agent loops
- Async httpx (`AsyncClient`) support
- Semantic request matching (model alias normalization, message-order invariance)
- PyPI publish (package installable from source only in v0.1)
- Provider-specific adapters (OpenAI vs Anthropic URL/body normalization)
- pytest fixture API (`llm_vcr` fixture) — decorator-only in v0.1
- CLI beyond basic health check

## 5. Architecture Delivered

```
pytest test
  └── @llm_vcr("cassette_name") decorator
          ├── resolve cassette path (LLM_VCR_CASSETTE_DIR)
          ├── record mode? (LLM_VCR_RECORD or missing cassette)
          └── httpx.Client(transport=VCRTransport)
                  ├── replay → find_interaction() → synthetic Response
                  └── record → wrapped HTTPTransport → save cassette YAML
```

### Module Layout

```
src/llm_vcr/
  ├── __init__.py
  ├── plugin.py       → @llm_vcr decorator, pytest hooks
  ├── transport.py    → VCRTransport (httpx.BaseTransport)
  ├── cassette.py     → Cassette, Interaction, find/record
  ├── redaction.py    → redact_dict() for secrets
  └── cli.py          → health command
```

### Technology Choices

| Layer | Choice | Rationale |
|-------|--------|-----------|
| Language | Python 3.9+ | Broader pytest ecosystem compatibility |
| HTTP | httpx | Modern client, transport hook API |
| Cassettes | YAML (`pyyaml`) | Readable PR diffs, hand-editable |
| Tests | pytest | Zero-config entry point via `pyproject.toml` |
| Packaging | hatchling | Modern `pyproject.toml` builds |
| Matching | SHA-256 hash of method + URL + JSON body | Deterministic, simple |

### Request Matching (v0.1)

| Input | Matching rule |
|-------|---------------|
| HTTP method | Exact string match |
| URL | Exact string match |
| Request body | Exact JSON dict match (sorted-key hash) |
| Headers | Not part of match key (v0.1) |

### Record / Replay Flow

| Mode | Trigger | Behavior |
|------|---------|----------|
| Replay | Cassette file exists and `LLM_VCR_RECORD` unset | Return recorded response; error if no match |
| Record | Cassette missing or `LLM_VCR_RECORD=true` or `--llm-vcr-record` | Live HTTP call, redact, append to cassette, save YAML |

### 6.2 pytest Integration

| Mechanism | Description |
|-----------|-------------|
| `@llm_vcr(name?)` | Decorator wraps test; injects `client` kwarg or `http_client` if in signature |
| `--llm-vcr-record` | pytest CLI flag sets `LLM_VCR_RECORD=true` |
| Entry point | Registered in `pyproject.toml` as pytest plugin |

### 6.3 Configuration

| Variable / Flag | Default | Description |
|-----------------|---------|-------------|
| `LLM_VCR_CASSETTE_DIR` | `tests/cassettes` | Directory for YAML cassettes |
| `LLM_VCR_RECORD` | `false` | Force record mode when `true`/`1`/`yes` |
| `--llm-vcr-record` | off | pytest flag equivalent to env var |

### 6.4 Cassette YAML Schema (v0.1)

```yaml
name: test_replay
interactions:
  - method: POST
    url: https://api.openai.com/v1/chat/completions
    request_headers: { ... }
    request_body: { model: gpt-4o-mini, messages: [...] }
    status_code: 200
    response_headers: { ... }
    response_body: { id: chatcmpl-test, choices: [...] }
```

### 6.5 Redaction Rules

| Pattern | Action |
|---------|--------|
| Key in `SECRET_KEYS` set (`authorization`, `api_key`, `x-api-key`, etc.) | Replace with `[REDACTED]` |
| Key contains `secret` or `token` (case-insensitive) | Replace with `[REDACTED]` |
| Nested dicts / lists of dicts | Recurse |

## 8. Known Limitations (v0.1)

| Limitation | Impact | Planned fix |
|------------|--------|-------------|
| Sync httpx only | Async test suites cannot use transport | v0.2 M3 `AsyncVCRTransport` |
| Exact JSON body matching | Minor payload drift breaks replay | v0.2 M4 semantic matching |
| No streaming replay | SSE chat completions cannot be tested | v0.2 M1 chunked cassette format |
| No tool-call loop support | Multi-turn agent tests need manual cassettes | v0.2 M2 sequence matching |
| Decorator injects `client` kwarg | Less idiomatic than pytest fixtures | v0.2 M5 fixture API |
| Headers excluded from match key | Same body, different auth header may false-match | v0.2 selective header matching |
| Not published to PyPI | Requires git/source install | v0.2 M5 PyPI release |
